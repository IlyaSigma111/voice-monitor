Преимущества

Почему VoiceMonitor?

Фоновая работа

Работает скрытно в системном трее. Ученики не заметят. Минимальное потребление ресурсов.

Полностью офлайн

Не требует интернета. Все данные остаются на компьютере. Приватность и безопасность.

Умное распознавание

Распознаёт коверканные слова, замены букв и сленг. Продвинутый алгоритм fuzzy matching.

Настраиваемый

Добавляйте свои слова. Меняйте чувствительность. Гибкая настройка под ваши нужды.

Подробный лог

Каждое событие записывается с датой, временем и распознанным текстом. Удобный журнал.

Для слабых ПК

Работает даже на старых компьютерах. ~50 MB RAM, минимальная нагрузка на CPU.

Принцип работы

Как это работает

01

Захват аудио

Программа слушает микрофон в реальном времени. Аудиопоток обрабатывается чанками по 200мс для минимальной нагрузки.

02

Распознавание речи

Движок Vosk на базе Kaldi транскрибирует речь в текст. Лёгкая модель small-ru (~50 MB) работает полностью локально.

03

Детекция мата

Продвинутый анализ: нормализация текста, fuzzy matching, проверка корней слов. Распознаёт даже коверканные слова.

04

Сохранение

При обнаружении аудиофрагмент сохраняется в папку recordings с меткой времени. Лог детекций ведётся автоматически.

Вопросы

Часто задаваемые вопросы

Нет. VoiceMonitor работает полностью офлайн. Модель распознавания речи загружается локально, а вся обработка происходит на вашем компьютере.

Приложение потребляет около 50 MB RAM и минимально нагружает CPU. Модель small-ru весит всего ~50 MB и оптимизирована для работы на слабых ПК.

Скачайте модель с официального сайта Vosk. Распакуйте архив в папку models/. По умолчанию используется vosk-model-small-ru.

Откройте файл profanity_list.py и добавьте нужные слова в список PROFANITY_WORDS. Для продвинутой детекции с нечётким поиском редактируйте profanity_detector.py.

Все записи сохраняются в папку recordings/ в формате WAV. Каждый файл содержит аудиофрагмент с меткой времени. Также ведётся лог детекций в формате detections_YYYY-MM.log.

# Нечёткое сопоставление для коверканных слов
def normalize_text(text):
    # Заменяем похожие символы
    mapping = {
        '@': 'а', '0': 'о',
        '$': 'с', '3': 'е',
        '*': 'а', '#': 'х',
    }
    for k, v in mapping.items():
        text = text.replace(k, v)
    return text

def detect_profanity(text):

            if Levenshtein.ratio(word, root) > 0.7:
