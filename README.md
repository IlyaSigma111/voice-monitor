# Voice Monitor

Фоновое приложение для мониторинга речи и сохранения фрагментов с нецензурной лексикой.

## Как это работает

1. Программа работает в фоне, слушая микрофон
2. Распознаёт речь в реальном времени (офлайн, без интернета)
3. При обнаружении мата сохраняет аудиофрагмент в папку `recordings/`
4. Иконка в трее для управления

## Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Скачивание модели Vosk

Скачайте лёгкую модель для русского языка:
https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

Распакуйте архив так, чтобы путь был:
```
models/vosk-model-small-ru/
```

### 3. Запуск

```bash
python main.py
```

Программа появится в трее (возле часов).

## Сборка в .exe

Запустите:
```bash
build.bat
```

Готовый файл: `dist/VoiceMonitor.exe`

## Структура проекта

```
voice-monitor/
├── main.py              # Основной скрипт
├── config.py            # Настройки
├── profanity_list.py    # Список слов для детекции
├── requirements.txt     # Зависимости Python
├── build.bat            # Скрипт сборки
├── models/              # Папка для модели Vosk
├── recordings/          # Сохранённые фрагменты
│   ├── detect_*.wav     # Аудиофрагменты с матами
│   └── detections_*.log # Лог детекций
└── monitor.log          # Лог работы программы
```

## Настройка

### Добавить/удалить слова
Откройте `profanity_list.py` и отредактируйте список `PROFANITY_WORDS`.

### Изменить параметры
В `config.py` можно настроить:
- `BUFFER_SECONDS` — сколько секунд до мата сохранять
- `SAMPLE_RATE` — частота дискретизации
- `RECORDINGS_DIR` — папка для записей

## Системные требования

- Windows 10/11
- Python 3.8+
- Микрофон
- ~50 MB RAM для модели
- Работает полностью офлайн
